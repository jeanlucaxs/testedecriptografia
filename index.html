Como este teste de segurança funciona?

Se você abrir o painel de desenvolvedor do navegador (F12) e tentar inspecionar o player acima ou monitorar a rede, você notará algo incomum. Este projeto foi programado para demonstrar técnicas básicas de proteção contra engenharia reversa e cópia direta de arquivos.

  • Mascaramento por Blob: Em vez de apontar o player para um arquivo direto como musica.mp3, o código gera um link virtual temporário iniciado em blob:. Esse endereço só existe na memória RAM desta aba e dá erro se copiado para outro lugar.
  • Sumiço na Aba Network (Rede): Se você limpar o histórico do F12 e clicar em "Mídia", verá que nenhum arquivo de áudio é listado. O download do arquivo original ocorre de forma invisível via JavaScript em formato binário bruto (ArrayBuffer).
  • Alimentação por Fragmentos (MSE): Utilizando a API MediaSource Extensions do HTML5, o navegador costura os dados binários direto na memória, alimentando o player aos poucos.
  • Bloqueio de Interface: O menu de clique direito sobre o player foi desativado e o botão nativo de download do navegador foi ocultado via código.

Nota técnica: Este projeto serve como um modelo didático. Sistemas de grande porte (como o Spotify) elevam essa segurança adicionando chaves de criptografia DRM (Widevine/FairPlay) aos fragmentos de rede.
